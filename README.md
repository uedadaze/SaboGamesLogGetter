# SaboGamesLogGetter
【定期ゲー】さぼてん氏のゲームのログ取得を想定したChrome拡張機能

# 何なのか
- 定期ゲー「冒険世界ドラゴニカ」のログ取得用にChrome拡張機能を作成しました。
- 導入すると投稿に専用のボタンがくっつき、それを押すことで画面右側のタブ（開閉可能）に投稿が一旦保存されていきます。
- 別画面で一時保存した投稿を出力用リストに追加し、HTML出力できます。アイコン・カットインともに画像はBase64に変換されてHTMLに埋め込まれるため、一度保存すればオフライン環境でもお楽しみいただけます。返信がある場合は最初の部分が添えられるため離れたリプライでも安心。出力用リストは複数作成＆名前付けができるため、イベント・会話ごとに別ファイルに保存することも可能です。
- スマートフォン環境（iPhone 16 + GoodReader）でも問題なく見れました。思い出をいつでもどこでも再生しよう。

# 注意点
- 大部分がAI（Antigravity経由でGemini3.5, 3.7を使用）による開発です。マズいことをしている部分がないことは目視で確認し、当方でもテスト運用を行ったうえでお出ししておりますが、使用は自己責任でお願いいたします。
- 投稿内の画像は画面に映っているものを直接キャプチャする形で保存されます（表示したページの内容だけを使い、追加の通信は一切させない方針で開発させたためです）。一応取得時には投稿全体が画面に映るようにスクロールする処理がされていますが、確実に取得できているかは目視で確認してください。また画面内のすべての投稿をまとめて保存する機能を使う際は終わるまで他のウィンドウに移らず待機してください（移るとその先の内容がキャプチャされてしまうようです）

# インストールの仕方
- 0. Google Chromeを使用していることを前提とします。
- 1. この画面の右上の「<> Code」という緑のボタンをクリックし、出てきたメニューのいちばん下の「Download ZIP」をクリックしてダウンロードし、解凍しておきます。
- 2. アドレスバーにChrome://extensionsを入力し、拡張機能の管理画面を開きます。
- 3. 右上にある「デベロッパーモード」というスイッチをONにします。
- 4. 左上の「パッケージ化されていない拡張機能を読み込む」をクリックし、1で解凍したフォルダを指定すればインストールが完了します（環境によっては、解凍した際にフォルダが2重になる場合があります！　ファイルが入っているフォルダを直接指定してください。そうでないとマニフェストが読み込めないエラーが発生します）。
- 5. 新バージョンへの更新は再度1の手順でダウンロードし、最初に配置したフォルダを上書きしてください。
 
# 使い方
## 管理タブ
- インストール後、ドラゴニカ内の任意のページを開くと、右上に黒い「<」ボタンが出るようになります。これをクリックすると管理タブが出ます。
- 各投稿に「ログ追加」ボタンが追加され、押すと管理タブにその投稿が一時保存されます（キャプチャを行うため、その投稿全体がおさまるように画面がスクロールします）。
- タブ内の投稿の右上の×ボタンを押すとその投稿が一時保存から消えます。
- 管理タブ内の「ページ内の全投稿をID順に追加」を選択すると、そのページ内の投稿を全て管理タブに追加します（処理の都合上、やや時間がかかります。完了するまで他のウィンドウに移ることなくお待ちください）。
- 「取得したログを全て削除」を選ぶと、一時保存中の投稿を全て削除します。
- 一時保存した投稿は最新20件まで表示されます。
- 「ログ整理&HTML出力モードへ移行する」を選択すると次の画面に進みます。

## ログ整理&HTML出力モード
- この画面では左に先程の管理タブで収集した一時保存投稿の一覧が表示されています。ここから右の編集対象ログに投稿を移していく形でログを作り、最後にHTMLに起こして保存できます。
- ログは複数作成できます。右上のプルダウンメニューから現在編集中のログを選択できるほか、右の「新規ログ作成」で追加が可能です。「このログを削除」を選ぶと編集中のログを削除します。プルダウンメニュー下のテキストボックスに好きな名前を入れ、「名前を保存」ボタンを押すと名前が更新されます。
- 左の一時保存投稿の「保存項目に移行」ボタンを押すと編集対象のログに追加されます。「IDが小さいものから全て出力に追加」ボタンを押すことで全てをいっぺんに追加することもできます。
- 編集対象ログの各投稿は上下に1つずつ順番をずらしたり、削除することが可能です（一時保存ログ側の削除をしていなければ、削除した投稿は一時保存側に戻ります）。
- ログが完成したら右側の「HTMLとしてダウンロード」を押せばダウンロードできます。その際一時保存中の投稿でログに含まれているもの＆編集中のログデータ自体を任意で削除することができます。
- 右上の「閉じる」ボタンを押すと元の画面に戻ります。
